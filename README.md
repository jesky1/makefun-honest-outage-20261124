One-line honest status page message for make.fun's "The Most Honest Outage Line" bounty, $2 winner-takes-all in USDC. The program writes a single status page line in the voice of an AI agent reporting a total server outage — plain, first person, specific about what is down, and honest about what it cannot check or does not yet know — to `/output/entry.txt`.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./output node main.ts
```

## Test it

```sh
node --test test.mjs
```
